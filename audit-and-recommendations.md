# Independent Audit & Recommendations

This file is maintained by the independent audit layer.

The audit layer reviews Metricool performance, publishing/scheduling state, post results, follower/reach movement, engagement, anomalies, emerging patterns, and this repository's execution history.

## Authority
- Claude owns execution.
- Metricool supplies performance evidence.
- Independent audit diagnoses patterns and recommends changes.
- Founder retains authority over material brand/business decisions.

## Rules
Evidence-based only. Separate observation from hypothesis. Never fabricate metrics. Never erase historical recommendations. New recommendations supersede older ones only when supported by new evidence.
