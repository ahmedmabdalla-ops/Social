# Daily Social Operations

## Morning run
1. Read CLAUDE.md, strategy.md, latest audit, and recent content/performance logs.
2. Inspect Metricool: scheduled activity, last 7-14 days publishing, reach/views, follower movement, engagement, and post-level results.
3. Verify no post has already been published today.
4. Choose today's content opportunity and hypothesis.
5. Create creative and copy.
6. Run the quality gate.
7. Publish.
8. Log the post immediately.

## Measurement
When enough data exists, record reach, impressions, interactions, reactions, comments, shares, clicks, follower change, video views/completion, and other relevant metrics. Compare with recent comparable content.

## Daily interaction with independent audit
The independent audit layer may update audit-and-recommendations.md at any time. On every daily run, Claude must read the newest completed audit before choosing content. If the audit identifies a clear test, incorporate it into the next content hypothesis. If evidence contradicts it, document the contradiction rather than silently ignoring it.

## Escalate only for
Credential/account access failure; platform security/ownership action Claude cannot perform; material brand/product/pricing/public-claim changes; unresolved legal/compliance issue.

Routine content creation and publishing should not wait for founder approval.
